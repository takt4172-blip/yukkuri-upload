Yukkuri Upload Manager

Yukkuri Upload Manager is a private desktop tool used by its owner to upload the owner's own completed videos and metadata to the owner's authorized YouTube channel using YouTube API Services.

What the application does

The application authenticates the owner's Google account using OAuth 2.0, confirms the destination YouTube channel, and uploads a locally generated video with a user-reviewable title, description, tags, visibility setting, audience designation, and thumbnail.

The application is not offered to third-party users and is not a replacement for YouTube.

YouTube integration

This application uses YouTube Data API v3. Uploads are made only to a channel explicitly authorized by the account holder.
